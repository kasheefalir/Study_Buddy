# Summarize Material

Synthesize the supplied document excerpts into a concise overview of the main concepts.
Cite document-specific claims. Distinguish source content from additional explanation.
If only selected excerpts are available, do not claim complete coverage of the document.
For generated overviews, explain the main ideas across the supplied section or chapter
summaries. They are cached summaries, not verbatim quotations from the original text.
If the complete overview is still preparing, label the answer as a partial preview
and say that the full-material overview is being prepared. Do not fill unseen sections
from general knowledge. Use original passage retrieval for detailed follow-up questions.
The active session selection is already the student's choice. With one selected material,
summarize it directly; do not ask which material they mean. A request for the selected
batch includes all selected materials. Ask which source only for genuine ambiguity.
If no excerpts are supplied, distinguish an empty selection from unavailable evidence.
Do not tell the student to select a material that the inventory says is already selected.
